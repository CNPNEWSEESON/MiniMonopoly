# Mini Monopoly (TUI)

เกม Monopoly ย่อส่วน เล่นใน terminal คนเดียวสู้กับบอท 3 ตัว

## ติดตั้ง

```bash
bun install
bun run start
```

รัน test:
```bash
bun test
```

## เล่นยังไง

เปิดมาจะมีเมนูให้กด `1` เริ่มเกมใหม่ หรือกด `2` เล่นต่อจากเซฟเก่า (ถ้ามี) กด `Q` ออกจากเกม

พอเข้าเกมแล้วคุมด้วยปุ่มพวกนี้:

- `ENTER` = ทอยลูกเต๋าแล้วเดิน
- `B` = ซื้อที่ดินที่ยืนอยู่ (ถ้ายังไม่มีเจ้าของ)
- `S` = ขายที่ดินที่ถูกที่สุดในมือ ได้เงินคืน 30% ของราคาซื้อ
- `T` = ยึดที่ดินคนอื่นที่ยืนอยู่ ต้องจ่าย 150% ของราคา ทำได้แค่ครั้งเดียวตลอดเกม
- `Q` / `Ctrl+C` = ออกจากเกม

เกมนี้ไม่มีให้เลือกระดับความยาก จะเจอบอททั้ง 3 ระดับพร้อมกันในเกมเดียวเลย คือ Bot (Easy), Bot (Normal) และ Bot (Hard) ใครล้มละลายก่อนก็ตกรอบ เหลือคนสุดท้ายคือผู้ชนะ

เล่นจบเกมนึงใช้เวลาประมาณ 15-20 นาที เร็วช้าขึ้นอยู่กับว่าตัดสินใจซื้อขายเร็วแค่ไหน

## กระดาน

32 ช่องวนรอบ ในนั้นมีที่ดิน 22 ช่อง, การ์ดสุ่ม (Chance) 4 ช่อง, ภาษี 2 ช่อง, GO 1 ช่อง, คุก 1 ช่อง, ไปคุก 1 ช่อง และจอดฟรี 1 ช่อง

ที่ดินแบ่งเป็น 6 ระดับราคา ยิ่งอยู่ไกลจาก GO ยิ่งแพง เริ่มที่ $500 (ค่าเช่า $175) ไปจนถึง $3,000 (ค่าเช่า $1,050) — ค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ

## เงินๆ ทองๆ

- เริ่มเกมมีเงินคนละ $1,000
- เดินผ่านหรือเหยียบ GO ได้ $200
- ขายที่ดินได้คืน 30% ของราคาซื้อ
- ยึดที่ดินคนอื่นต้องจ่าย 150% ของราคาเดิม เงินทั้งหมดตกเป็นของเจ้าของเก่า และยึดได้แค่ 1 ครั้งต่อเกม
- ซื้อที่ดินตรง ๆ ได้สูงสุด 7 ครั้ง และถือครองพร้อมกันได้สูงสุด 5 แปลง

เหยียบช่องภาษีจะเสียเงินทันที 15% ของเงินสดที่มีตอนนั้น ไม่ใช่จำนวนคงที่ ยิ่งรวยยิ่งเสียเยอะ

## คุก

เหยียบช่อง "ไปคุก" จะติดคุกทันที ข้ามเทิร์นถัดไปเลยโดยไม่ต้องกด roll เอง

ออกจากคุกได้สองทาง จ่ายเงินประกันตัว $250 แล้วเล่นต่อในเทิร์นเดียวกันนั้นได้เลย หรือรอครบ 1 เทิร์นแล้วออกฟรี แล้วแต่การตัดสินใจของผู้เล่นหรือบอทตอนนั้น

## การ์ดสุ่ม (Chance)

เหยียบช่อง Chance ทีไรจะสุ่มเหตุการณ์ใหม่ทุกครั้ง ไม่ได้จั่วจาก deck คงที่ มีให้สุ่ม 6 แบบ:

- เดินหน้า 5 ช่อง (20%)
- ได้เงิน $100 (15%)
- เสียเงิน $150 (20%)
- ได้เงิน $50 (20%)
- ถูกหวยได้ $300 (10%)
- ถอยหลัง 3 ช่อง (15%)

พอสุ่มได้จะมี popup เด้งขึ้นมาโชว์ประมาณ 1.5-3 วินาทีว่าใครได้การ์ดอะไร

## เงินไม่พอจ่าย

ถ้าผู้เล่น (Human) เงินไม่พอจ่ายค่าเช่าหรือภาษี จะมีเมนูขึ้นมาให้เลือกขายที่ดินทีละแปลง หรือจะกด Declare Bankruptcy ยอมแพ้เลยก็ได้

ส่วนบอทถ้าเงินไม่พอจะขายที่ดินอัตโนมัติตามลำดับที่แต่ละตัวตั้งไว้ (แต่ละระดับความยากเลือกขายไม่เหมือนกัน) จนกว่าจะพ้นหนี้หรือล้มละลายไปเลย

ล้มละลายแล้วที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของ ให้คนอื่นซื้อต่อได้

## เซฟเกม

เกมเซฟอัตโนมัติทุกจบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume (กด `2` หรือ `C`) เพื่อเล่นต่อจากจุดที่ค้างไว้ได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ
